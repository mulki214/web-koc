# Knockout Club — project overview

Knockout Club is an Indonesian boxing promotion, fighter, and editorial platform. The public experience is in Bahasa Indonesia and uses an original dark, red, and white visual identity. The official domain is `https://knockoutclub.id`; official Instagram is `@knockout.club_id`.

Phase 1 delivers public event, fighter, news, media, about, and contact pages; a protected content editor foundation; curated Instagram links; metadata; and a relational model. Phase 2 adds private fighter applications, event registration, review, and results operations. Phase 3 adds credentialed social provider integrations. Ticketing and payment remain future work.

All local sample data is explicitly marked demo. No fictional item represents a real Knockout Club announcement, fighter record, result, or achievement. Public content must be reviewed before publication.

Design tokens live in `src/app/globals.css`. The generated ring photograph in `public/images/boxing-hero.webp` is an original project asset; it depicts anonymous people and is decorative.
